# Dictionaries

## Yomitan

[Yomitan](https://yomitan.wiki/) is a web extension popup dictionary for many languages.

#### Kakki-to-Yomitan
Yomitan-compatible dictionaries from wikitionary data. Includes nearly any language combination so you can get zh-eng, zh-zh, jp-en etc.
[GitHub](https://github.com/yomidevs/wiktionary-to-yomitan)

#### Kroll's Student Dictionary of Classical and Medieval Chinese (Yomitan version)
A English dictionary for classical chinese.
This is a reformatted version of the previous Kroll's SDCMC yomitan dictionary
[Drive](https://drive.google.com/file/d/12yptLk4ePa-diUWCqHUp1Dve0rWwE2q9/view?usp=sharing)

#### Vogelsang's Classical Chinese Dictionary
The glossary from Vogelsang's Introduction to Classical Chinese reformatted into a Yomitan dictionary. Includes his innovative word classifications. Excellent for understanding a word's function in a sentence or for using alongside his textbook.
[Drive](https://drive.google.com/file/d/1LFKRNSyd_T_6zSWICgyKZ5edULICtPBr/view?usp=sharing)
